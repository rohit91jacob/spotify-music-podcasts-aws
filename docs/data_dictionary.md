# Data dictionary

Generated by `scripts/gen_data_dictionary.py` from the dbt contract YAML and the raw Arrow
schemas. Timestamps are UTC without a zone. Locally the layers are DuckDB schemas `raw`,
`staging`, `intermediate` and `marts`; on Athena they are the Glue databases
`musicpods_raw`, `musicpods_staging`, `musicpods_intermediate` and `musicpods_marts`.

## Raw (Iceberg) tables

Written by the Glue-style jobs (`src/musicpods/glue/jobs.py`) and the Firehose sink, each
behind a data-quality gate (`src/musicpods/quality/checks.py`).

| Column | Type | Description | Tests |
| --- | --- | --- | --- |

| `artist_mbid` | varchar | MusicBrainz artist MBID (null for unmapped artists). |  |
| `artist_name` | varchar | MusicBrainz name when looked up, else the most frequent credited name in the listens. |  |

| `country` | varchar | MusicBrainz artist country (ISO 3166-1 alpha-2), when known. |  |

| `listeners_total` | bigint | Distinct panel users who listened. |  |

#### `marts.fct_listens`

One row per non-duplicate listen (duplicate scrobbles of the same recording within `duplicate_scrobble_seconds` are dropped), with session and short-play attributes.

| Column | Type | Description | Tests |
| --- | --- | --- | --- |

| `listened_at` | timestamp | When the listen started (UTC), as submitted by the user's client. | not_null |
| `listen_date` | date | UTC date of listened_at. |  |
| `week_start` | date | Monday of the ISO week of listen_date. |  |
