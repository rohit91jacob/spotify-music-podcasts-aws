## Simulated data

`tests/fixtures/bronze/apple/` and `tests/fixtures/bronze/rss/` are **simulated**: generated by
`scripts/make_synthetic_podcast_fixtures.py` with a fixed seed, every show named
`SYNTHETIC Show NN`, ids starting at 900000001 and URLs on the reserved `.invalid` domain. Each
payload carries `"_synthetic": true`. They exist only so that tests and CI can exercise the
podcast models without redistributing Apple's or publishers' data. The results site says so
whenever it is built from them. Real podcast numbers in the README and on the published site
come from live downloads.

## Privacy

ListenBrainz listens are public, but user names never leave the ingest step: every landed record
carries `user_key`, a salted SHA-256 pseudonym, and error messages are redacted before they are
logged. The salt is generated into the data directory (or supplied as
`MUSICPODS_PSEUDONYM_SALT`) and is never committed. Only the client fields the pipeline needs are
kept (an allowlist in `src/musicpods/sources/listenbrainz.py`); origin URLs, player names and
third-party ids are dropped.
